# Experimento de Controle (telemóvel)
Testa um esquema tipo consola para o RTS: joystick do polegar esquerdo move a câmara, o ponto fixo no centro é a mira, e os botões A/B/X/Y (estilo Xbox) agem sobre o que a mira aponta.
Como usar: arrasta na metade esquerda para mover a câmara; mira com o ponto; A seleciona/ordena, B cancela, X é a ordem inteligente, Y volta à base. Com um aldeão selecionado, segura o dedo no ponto central (~180 ms) para abrir o menu radial: gira o dedo à volta do centro para destacar uma fatia (Mover · Recolher · Atacar · Casa · Fazenda · Parar) e solta para confirmar — soltar no centro ou fora do anel cancela. A página deteta a orientação: com o telefone virado (paisagem) fica como uma consola — mover à esquerda, botões à direita; em retrato os botões encolhem e aparece o aviso para virar o telefone.
Tudo corre numa página isolada com um mini-mundo de teste (base, árvores, bagas, unidades) — não usa o motor do jogo.
