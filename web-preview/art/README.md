# Skirmish — site artwork

All images in this folder are **original artwork generated for the Skirmish
project** (AI-generated with Muse's media tools, October 2026). They are not
screenshots, not derived from any commercial game, and contain no third-party
game art, logos, or trade dress. Any lettering on the site is rendered as HTML
text — the images themselves are text-free.

| File | Use |
| --- | --- |
| `hero-key-art.jpg` | Hero key art on the project page: an original painterly isometric medieval RTS landscape — village, working villagers, pine forest, gold outcrop and stone quarry in warm late-afternoon light. |
| `og-card.jpg` | Social sharing card (`og:image` / `twitter:image`): a painterly great hall on a green hill with two villagers at work, simple composition with generous negative space. |
| `emblem.webp` | Skirmish emblem: a round wooden shield with iron bands, two crossed golden swords and a small castle tower on a deep green field. Used in the header, hero and as the site favicon. An original design using generic medieval motifs. |
