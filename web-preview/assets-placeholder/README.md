# Placeholder Test Art (CC0)

These sprites are **temporary placeholder art for the test/preview build
only**. They exist so the playable preview already looks like a game
while our own original art is produced piece by piece (villager first).
Each placeholder will be deleted as the corresponding original sprite
lands — nothing in this folder is part of the final game's art.

Every asset below is **CC0 / public domain** — no attribution required,
no commercial-use restriction. No art from any commercial game is used
anywhere in this project (clean-room rule).
