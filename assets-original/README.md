# Original Art (ours)

These sprites are **Skirmish's own original art**, generated by our
sprite pipeline from procedural low-poly models written in code
(`tools/sprite-pipeline/render.py`). No external art, no reference
models, nothing copied — clean-room, like everything else in this
project. Method spec: `SPRITE-PIPELINE.md` (goal files).

## Sheets

Layout for every sheet: rows = 8 facing directions (LOW tier; row 0
faces +X / screen down-right, increasing toward +Y), columns =
animation frames. Cell 128x128 px, feet-center anchor at (64, 110).

| File | State | Frames | Notes |
|---|---|---|---|
| `villager-idle.png` | idle | 4 | breathing loop |
| `villager-walk.png` | walk | 8 | stride-locked to distance travelled |
| `villager-gather.png` | gather | 4 | chop cycle |
| `villager-carry.png` | carry | 8 | walk + bundle held overhead |

Villager v1: original low-poly humanoid (tunic in player color, belt,
trousers, boots, hair cap), built from tapered boxes posed by joint
angles. Default player color: blue `#2e6fd8` — regenerate per player
color with `--player-color` (see the pipeline README).

Generated 2026-10-16 by `tools/sprite-pipeline/render.py`.
