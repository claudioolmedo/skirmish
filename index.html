Why Skirmish

Most strategy games demand new hardware, a big download and a store account. Skirmish goes the other way: a complete little RTS that lives in a browser tab, engineered so anyone can play — and anyone can read how it works.

Deterministic simulation

The whole game is a pure Rust simulation with fixed-point math and a seeded RNG. Same seed, same commands, same result — on every machine, every time. That is what makes replays, spectating and fair multiplayer possible.

Adaptive quality

One build for every computer. The simulation never changes; only the visuals scale to what your machine can handle — so a modest laptop and a gaming rig compete evenly.

Clean-room & original

Every sprite and every line of code is made for Skirmish, from scratch. Inspired by the classics, built on public knowledge — never on anyone else's assets.

Built in the open

The source lives on GitHub and the game is developed in public, milestone by milestone. Play the test build, read the code, follow along — or fork it.
